# MARUDI — Creative Digital Studio

Одностраничный сайт. Открыть `index.html` в браузере.

- `assets/video/` — главная анимация (hero.mp4 / hero.webm, петля 10 с)
- `assets/logo/` — знак MARUDI (graphite, ivory, bold для favicon)
- Контакты (Telegram, Instagram, e-mail) — заглушки в блоке `#contact` в index.html
