# Бот MARUDI (@marudi_studio_bot)

Бот без рекламы: здоровается, показывает меню, пересылает Марии сообщения клиентов
и отправляет клиентам её ответы. Работает бесплатно на Cloudflare Workers.

Код — `worker.js`. Токен бота в нём не хранится, он задаётся в настройках Cloudflare.

## Запуск

1. **Отключить Livegram и обновить токен.** В @BotFather: `/revoke` → выбрать
   @marudi_studio_bot → получить новый токен. Старый токен (который знает Livegram)
   перестанет работать. В @LivegramBot удалить бота из списка.
2. **Аккаунт Cloudflare.** Зарегистрироваться на https://dash.cloudflare.com/sign-up (бесплатно).
3. **Создать Worker.** Workers & Pages → Create → Create Worker (шаблон «Hello World»).
   Имя: `marudi-bot` → Deploy.
4. **Вставить код.** Edit code → удалить всё в файле → вставить содержимое `worker.js` → Deploy.
5. **Переменные.** Worker → Settings → Variables and Secrets → Add:
   - `BOT_TOKEN` — тип **Secret**, новый токен из шага 1;
   - `WEBHOOK_SECRET` — тип **Secret**, любая длинная строка из латинских букв и цифр;
   - `ADMIN_ID` — тип Text, пока можно не добавлять (см. шаг 7).
6. **Подключить бота.** Открыть в браузере
   `https://marudi-bot.<ваш-поддомен>.workers.dev/setup?secret=<WEBHOOK_SECRET>`.
   Должно появиться «Готово! Бот подключён.»
7. **Узнать свой id.** Написать боту `/myid`, он пришлёт число. Добавить переменную
   `ADMIN_ID` с этим числом (тип Text) → Deploy.

## Как пользоваться

- Сообщения клиентов приходят в чат с ботом с подписью «✉️ Имя (@ник) #id…».
- Ответить клиенту: свайп влево (или «Ответить») на его сообщении → написать текст.
  Бот отправит его от имени MARUDI и напишет «✓ Отправлено».
- Тексты приветствия, меню и автоответа — в начале `worker.js`, в объекте `TEXT`.
