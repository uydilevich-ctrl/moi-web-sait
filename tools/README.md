# Рабочие инструменты MARUDI

Не часть сайта — исходники и скрипты, которыми собраны видео, логотип и обложки.

- `video/` — исходные ролики и скрипты сборки видео главного экрана (`comp.py`)
  и шоурила (`showreel.py`). Запускать из папки `video/`: сначала `comp.py`
  (даёт `tmp_lossless.mp4`), затем `showreel.py`. Подробности — в CLAUDE.md.
- `logo/` — оригинал логотипа Марии и скрипт векторизации `vec.py` (potracer).
- `covers/` — HTML-шаблоны обложек постов 1080×1350 и скрипт `oct.py`
  (рендер через Playwright + Chromium в `/opt/pw-browsers`).
